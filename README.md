## Contact form -> HTML PROJECT

A simple multi-page customer support website built using only HTML. This project demonstrates the use of semantic HTML elements, navigation links, forms, and multiple web pages without using CSS or JavaScript.

## Live Demo

Project URL: https://github.com/CodeMasterAshish/Html-contact-form

## Features

* Multi-page website
* Home page
* Help Center page
* Contact page
* Navigation links between pages
* Contact form with:

  * Full Name field
  * Email field
  * Subject dropdown
  * Message textarea
  * Radio button selection
  * Newsletter subscription checkbox
* Semantic HTML5 structure

## Project Structure

```text
acme-support/
│
├── index.html
├── help.html
└── form.html
```

## Pages

### Home (`index.html`)

* Welcome section
* Services overview
* Quick links

### Help (`help.html`)

* Frequently Asked Questions
* Support topics
* Contact support link

### Contact (`form.html`)

* Contact form
* User information fields
* Support topic selection
* Message submission section
